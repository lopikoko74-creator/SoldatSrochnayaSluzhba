# СОЛДАТ: СРОЧНАЯ СЛУЖБА

Android-игра на Kotlin и Jetpack Compose. Ранняя версия 0.1.0.

## Возможности прототипа
- Три карьерных пути: срочная служба, контракт, офицер.
- Интерактивные события с выбором и последствиями.
- Характеристики персонажа и журнал событий.
- Локальное автосохранение.

## Сборка
Откройте проект в Android Studio с JDK 17 и Android SDK 35, выполните Gradle Sync, затем Build → Build APK(s).

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

Это ранний прототип, а не завершённая игра. APK пока не собран и не проверен.
